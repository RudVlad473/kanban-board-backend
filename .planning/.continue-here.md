## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Docker-dependent pre-commit hook | This repo's `.githooks/pre-commit` runs a real gitleaks scan via Docker (plus spotlessCheck/fastTest) on every commit, including docs-only ones. If Docker Desktop isn't running, the commit fails with "failed to connect to the docker API" — this happened this session. | advisory | Before any commit, if it fails on the Docker connection specifically (not a real gitleaks finding), start Docker Desktop and wait for `docker info` to succeed before retrying — do not use `--no-verify`. |
| Cold Gradle daemon reads as a hang | The pre-commit hook also runs `spotlessCheck`/`fastTest` regardless of file type. The first commit after a while can take 1-2 minutes while Gradle's daemon cold-starts — this looks identical to a hang from inside a tool-call timeout. This session, a truncated first attempt left a stale `.git/index.lock`. | advisory | If a commit call times out or seems stuck, check for a live `git.exe` process before assuming corruption; if none is running, the lock is safe to remove and the commit safe to retry with a longer timeout. |

**Severity values:** `blocking` — resuming agent must pass understanding check before proceeding. `advisory` — important context, does not gate resumption.
