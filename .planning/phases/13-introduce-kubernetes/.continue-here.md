## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Netcup Cloud Firewall (Layer 2) masks the off-box proof for a NEW Layer 3 host firewall rule | The plan's Task 3 verify method requires an off-box `nc -z` probe to fail AND a mangle-table DROP counter to increase for the same packet. Do not treat "probe times out" alone as sufficient proof — the counter must move too, or the deviation must be explicitly documented as a substitute proof. |
