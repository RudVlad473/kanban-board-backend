## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Fixed the `SecurityConstants.SESSION_NAME` dead-static-field bug (F3)**
- **Found during:** Task 2 (scan-finding triage)
- **Issue:** `SecurityConstants` had no `@Component`/`@Configuration`, so its `@Value`-annotated static field was never populated by Spring — it stayed `null` forever. `SecurityConfiguration`'s `logout.deleteCookies(SecurityConstants.SESSION_NAME)` therefore always registered a `CookieClearingLogoutHandler` with a single `null` cookie name; the Servlet API's `CookieNameValidator` rejects `new Cookie(null, null)` with `IllegalArgumentException`, thrown from inside `LogoutFilter` before `DispatcherServlet` ever ran. Every real `POST /api/logout` 500'd. Confirmed by direct bytecode inspection of `CookieClearingLogoutHandler`/`Cookie`/`CookieNameValidator` (Spring Security 6.5.0 / Tomcat embed 10.1.41) before writing any code, then empirically confirmed with a RED test.
- **Fix:** `SecurityConfiguration` now reads the cookie name via a real `@Value`-injected instance field (`sessionCookieName`) instead of the dead static one. `SecurityConstants.java` deleted outright — it had no other callers.
- **Files modified:** `src/main/java/com/vrudenko/kanban_board/security/SecurityConfiguration.java`, `src/main/java/com/vrudenko/kanban_board/constant/SecurityConstants.java` (deleted), `src/test/java/com/vrudenko/kanban_board/security/AuthenticationTest.java`
- **Verification:** New `AuthenticationTest.Logout.shouldClearSessionCookieAndReturnOk_whenLogoutSucceeds` test. Confirmed RED (`IllegalArgumentException` at the exact predicted line) before the fix, GREEN after. Full suite green (382/382, 0 failures) after the fix.
- **Committed in:** `96b3f5b` (Task 2 commit)

**2. [Rule 1 - Stale doc] Fixed 3 stale `SessionPersistenceE2ETest` citations found while reconciling documentation**

Resolved by `./gradlew --stop` plus deleting the locked directory before retrying — not a code defect, a leftover-process artifact of retrying commits under a tool timeout.

No commit with a skipped hook exists in the final history.
