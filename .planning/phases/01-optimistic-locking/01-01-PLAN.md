<objective>
Deliver the end-to-end optimistic-locking tracer for Task: prove that two concurrent conflicting updates to the same task surface as HTTP 409, wired through every layer (entity @Version → required version on the update DTO → explicit server-side version check in the service → the corrected exception-handler mapping → an E2E test asserting the 409 status code). This is the thinnest complete path that touches every seam the phase modifies, and it is production-quality (not a prototype). ColumnEntity's @Version + Lombok exclusion is added here too (one atomic entity change), so Plan 02 can build the Column update endpoint on top of it.

Purpose: Concurrent drag-and-drop edits to the same task must be detected and rejected with 409 instead of silently overwriting each other. This proves the architecture end-to-end before expanding to the Column endpoint and remaining edges.
Output: @Version on TaskEntity and ColumnEntity; version fields on Task request/response DTOs; explicit version check in TaskService.updateById; the 423→409 GlobalExceptionHandler fix; a passing E2E test asserting HTTP 409 on a stale-version task update.
</objective>
