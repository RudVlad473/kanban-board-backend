## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 3 - Blocking] Pre-existing test files failed to compile after Task 1's type change, blocking every commit via the pre-commit hook**
- **Found during:** Task 1, first commit attempt
- **Issue:** The repo's `.githooks/pre-commit` hook runs `spotlessCheck` and `fastTest` (which compiles the entire test tree) on every commit. 9 pre-existing test files typed local `eventId` variables as `UUID` and failed to compile against the new `String` signatures — this is the exact "expected blast radius" Task 3 describes, but the hook forced it into Task 1's commit rather than allowing it to land in Task 3 as the plan's task boundaries suggested.
- **Fix:** Widened local `eventId` variables/parameters from `UUID` to `String` and appended `.toString()` at each `UUID.randomUUID()` call feeding an `eventId`, across all 9 files. No assertion was weakened and no test behavior changed — this is a mechanical type-widening, not a logic change.
- **Files modified:** listed above.
- **Verification:** `./gradlew fastTest` green before the commit; full suite (278 tests) confirmed green later in Task 3.
- **Committed in:** `11fb2ad` (Task 1 commit, combined out of necessity)

**2. [Rule 3 - Blocking] Task 3's suggested file (`ActivityLogConsumerE2ETest.java`) did not need a new republish-dedupe test**
- **Found during:** Task 3
- **Issue:** The plan's Task 3 asks to "add or extend one end-to-end case proving the dedupe path still works with the new key type," naming `ActivityLogConsumerE2ETest.java` as the file to touch. That exact case already exists — `ActivityLogIdempotencyE2ETest.RedeliveryTest.shouldPersistExactlyOneRow_whenEventRedeliveredThroughRealBroker`, written in an earlier phase — and now exercises the new `String` key type unchanged (it publishes an event, republishes the identical event, and asserts exactly one row).
- **Fix:** No new test added — the existing coverage in the correct, already-established location (`ActivityLogIdempotencyE2ETest`, not `ActivityLogConsumerE2ETest`) satisfies the requirement. Adding a duplicate case would be scope creep with no new coverage.
- **Verification:** Full suite run (`./gradlew spotlessCheck test`) confirms this test passes at 278 total tests, 0 failures.
- **Committed in:** n/a — no code change required for Task 3.
