## Spring Session table ownership

| Option | Description | Selected |
|--------|-------------|----------|
| Leave Spring Session as-is | Spring Session's own initializer (`initialize-schema=always`) keeps creating SPRING_SESSION tables; Flyway only manages app domain schema | ✓ |
| Bring under Flyway | Single source of truth for all schema, including session tables; extra surface area for a table Flyway doesn't need to manage | |

**User's choice:** Leave Spring Session as-is
**Notes:** Recommended option — avoids two schema-creation mechanisms touching the same tables.
