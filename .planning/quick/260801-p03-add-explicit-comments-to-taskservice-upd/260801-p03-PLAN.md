<objective>
Add an explicit in-method comment directly above the version-check `if` block in `TaskService.updateById` and `ColumnService.updateById`, stating that the client-supplied `dto.getVersion()` is used only for the stale-write equality comparison and is never written onto the entity — the actual persisted version increment is owned entirely by Hibernate's `@Version` mechanism at flush.

Purpose: a prior discussion surfaced a misreading of this code — that the client-submitted `version` becomes the next persisted version. It doesn't; `dto.getVersion()` never touches the entity. Both methods already carry a method-level Javadoc explaining *why* an explicit check is needed, but neither states *where the persisted version actually comes from* right at the line where a reader could make that same mistake. This plan closes that specific gap with a comment, not a Javadoc rewrite.

No tracer task in this plan: this is a comment-only addition to two already-correct, already-tested methods — there is no new capability, layer, or path to wire end-to-end. A thin slice would add no information.
