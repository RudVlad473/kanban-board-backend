## Approach and trade-offs (project directive: alternatives, matrix, non-obvious trade-offs)

**Core data flow (3 sentences):**
1. The gate asks git for the tracked paths and picks the always-loaded roots: `CLAUDE.md`,
   `.claude/CLAUDE.md`, `CLAUDE.local.md`, `AGENTS.md`, `.claude/AGENTS.md`, `GEMINI.md`, and any
   `.claude/rules/**/*.md` without a `paths:` frontmatter key.
2. It follows every `@` import outside code spans and fences, resolved against the importing
   file's directory, for up to 5 hops. It sums the raw bytes of that manifest and fails if the
   total exceeds CEILING_BYTES, if an import leaves the repo, or if no root exists.
3. The pre-commit hook runs it on the working tree and CI runs selftest-then-gate on the checkout,
   so an instruction file can grow only through a reviewed edit to one number.

**Non-obvious trade-offs:**
- **Cost:**
  - The gate is O(total bytes), milliseconds. It adds under a second to the 4-minute hook, and the
    CI job takes about 15 s.
  - The trigger rewrite also runs the other four invariant jobs on a change that touches only an
    instruction file, a few CI minutes on such PRs.
- **State:**
  - The ceiling moves only when someone edits it. After a trim, the gate prints an advisory with
    the number to lower it to and never auto-lowers. This mirrors context-budget.js's opt-in
    `--ratchet`, without its per-machine state file.
  - Raw bytes overcount what Claude Code injects: stripped HTML comments still count. That is
    conservative and also right for runtimes that do not strip.
- **Security:**
  - The trigger rewrite could silently stop every invariant job (T-jh9-04). Mitigations: the
    ordered list is equivalent under both glob readings, a YAML assertion checks the exact list,
    and the PR run must show all five jobs.
  - An import pointing outside the repo is a violation. Its size is unbounded and depends on the
    machine.
- **Known holes, recorded in the gate's docstring:**
  - SessionStart hook output, skill descriptions and MCP server instructions are always-loaded
    context but are not instruction files.
  - Nested per-directory CLAUDE.md files load on demand.
  - An untracked personal `CLAUDE.local.md` is not counted.
  - CI's path filter still skips growth of an imported file under docs/; pre-commit catches it.

## Conventions and gotchas

- Services and controllers inject collaborators with field `@Autowired`, and `@Transactional` is
  `jakarta.transaction.Transactional`: match the neighbouring class.
- Entity ids are base36 RandFlake strings (`config/RandFlakeGenerator.java`), not ULIDs; the
  `ulid-creator` dependency in build.gradle is unused.
- Every test, `fastTest` included, runs on Testcontainers PostgreSQL built by the real Flyway
  migrations, so Docker must be running. Assert query counts through `AbstractAppTest.countQueries`,
  which reads `getPrepareStatementCount()`; `getQueryExecutionCount()` misses `findById()`.
- Write code comments as plain text: identifiers by bare name, a blank comment line between
  paragraphs, `- ` for each list item (docs/CODE_STYLE.md rule 14, enforced by scripts/verify-comments.py).
- Every commit runs `.githooks/pre-commit`, about 4 minutes: gitleaks on the staged diff, the comment
  lint, the instruction-file budget, `spotlessCheck` (`./gradlew spotlessApply` fixes it) and
  `fastTest`. Gitleaks refuses a credential-shaped value anywhere, `.planning/` prose included; a
  genuine false positive gets a narrow, evidence-cited entry in `.gitleaks.toml`.
- Inspecting live output (the OpenAPI document, a real HTTP response): run the app on the host and
  `curl` it rather than writing a throwaway test class. Commands and their port and path gotchas:
  docs/LOCAL_DEV.md, section "Inspecting live output".
