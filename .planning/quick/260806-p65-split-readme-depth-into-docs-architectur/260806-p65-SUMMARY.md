## Research basis

The restructure was driven by measurement, not preference:

- README at HEAD~1 was 2,265 words / 267 lines ≈ a 10-minute read, with "Running it locally" 10th of 11 sections.
- Recruiters spend 10–30 seconds deciding whether to keep reading and 2–5 minutes at most on a portfolio.
- The standard-readme spec orders sections Title → Description → TOC → Install → Usage, and recommends a TOC past 100 lines.
- Comparable Java repos: `spring-petclinic` 178 lines, `eugenp/tutorials` 128 lines. The 600–800 line Java READMEs found (`java-design-patterns`, `ddd-by-examples/library`) are teaching repos where the README *is* the product — not this case.
