## Non-obvious trade-offs (per CLAUDE.md's PLAN.md directive)

- **This job's other two actions are not in scope and may carry their own warnings.** `appleboy/scp-action@v1.0.0` and `appleboy/ssh-action@v1.2.5` also execute in this job. - **Verification requires a production deploy.** `deploy.yml` fires on `push: branches: [master]` only, and this job is the one that SSHes into the live Netcup VM. A stated, deliberate deviation from the global branch-per-work-item preference, forced by the workflow's own trigger config; STATE.md records plan 05-05 and quick task 260816-sv1 doing exactly this.
- **A run may already be in flight.** Run `31968657541` (head `7007b89`) was still executing at planning time. `deploy-to-netcup` carries `concurrency: { group: deploy-to-netcup-vm, cancel-in-progress: false }`, so this task's push **queues behind** any in-flight deploy rather than cancelling it. Expect the wall-clock, do not interpret the queue wait as a hang.
- **Supply chain (mutable tags).** `@v5` is a moving tag that retargets on each minor release. This repo pins its gitleaks scanner by tag *plus* digest but pins every GitHub Action by tag alone -- a known inconsistency already filed as `.planning/todos/pending/2026-08-16-digest-pin-github-actions-mutable-tags-are-currently-trusted-by-tag-only.md`, whose text already anticipates `checkout@v5`.
