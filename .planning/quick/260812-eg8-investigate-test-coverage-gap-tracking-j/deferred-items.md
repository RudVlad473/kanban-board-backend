## 1. `GlobalExceptionHandlerTest.AccessDeniedTest` is flaky against RFC 7807's literal `"about:blank"`

**File:** `src/test/java/com/vrudenko/kanban_board/handler/GlobalExceptionHandlerTest.java`
(`AccessDeniedTest.shouldReturnForbiddenWithAccessDeniedCode_andDiscloseNothing_whenBoardOwnedByAnotherUser`)

**Observed:** intermittent failure (twice, both during `./gradlew fastTest`/`./gradlew test` runs
in this session, unrelated to any file this task touches):

```
Expecting actual:
  "{"type":"about:blank","title":"Forbidden","status":403,"detail":"...","instance":"...","code":"ACCESS_DENIED"}"
not to contain:
  "about"
```

**Root cause:** the test asserts the response body does not leak the other user's board name via
`Assertions.assertThat(response.getContentAsString()).doesNotContain(otherBoard.getName())`. The
board name is generated by `dataFactory.getRandomWord(...)`, which occasionally produces the word
`"about"` (or a name containing it as a substring). Every `ProblemDetail` response from Spring's
default RFC 7807 serialization carries the literal `"type":"about:blank"` field, so on the unlucky
draw the assertion's `doesNotContain` check fails against that unrelated boilerplate field, not
against an actual data leak.

**Why not fixed here:** this file is not in this quick task's `files_modified` list and was not
touched by the relocation/fold/split work; SCOPE BOUNDARY reserves pre-existing, unrelated
failures for their own todo rather than folding them into this task's diff. Verified in isolation
(`./gradlew test --tests GlobalExceptionHandlerTest`) that the test passes reliably when it does
not draw an unlucky random word -- this is pre-existing flakiness, not a regression from this
task's changes.

**Suggested fix (for the follow-up todo):** scope the assertion to a value that cannot collide
with RFC 7807 boilerplate, e.g. assert `otherBoard.getName()` does not appear in the `detail` field
specifically (`objectMapper.readTree(...).get("detail").asText()`) rather than the raw response
body string, or exclude data-factory words that are substrings of `"about"`/`"blank"`/other
RFC 7807 constants.
